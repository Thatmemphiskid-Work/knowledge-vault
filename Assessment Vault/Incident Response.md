# Incident Response

Vulnerability verification and compromise investigation answer different questions. A fixed version can still contain persistence or previously stolen secrets.

- Follow the CSV's forensic-triage field and linked instructions where applicable.
- Preserve relevant logs and artifacts before remediation if investigation is required.
- Determine exposure period, access history and indicators relevant to the actual advisory.
- Restrict access, apply the vendor fix and validate behavior.
- If compromise is suspected, use your organization's response process for eradication, credential rotation and recovery. Do not call a patch alone incident closure.
- In a reproduction bench, label test-induced events separately from historical events.
