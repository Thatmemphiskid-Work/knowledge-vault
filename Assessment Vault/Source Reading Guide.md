# Source Reading Guide

All supplied PDFs are indexed by exact PDF page, with original files available in the app's Document Library. Source notes preserve embedded tables of contents where present. PDF page numbers can differ from printed numbers.

## Assessment-oriented routes
- [[book-01]] — Gray Hat Hacking: PDF page 34 introduces programming/research, red/purple teaming, platform exploitation and malware-analysis areas. Use for background; not a current CVE-version database.
- [[book-02]] — Attacking Network Protocols: protocol capture/analysis and application reverse engineering; PDF page 167 explains .NET assemblies and the CLR. Useful when product identity and protocol behavior require deeper investigation.
- [[book-03]] — Beginning Ethical Hacking with Python: language fundamentals and networking. Keyword search for “enumeration” can hit Python's `enumerate()` discussion (PDF page 80), not security enumeration—review context.
- [[book-04]] — CEH v10 guide: printed contents visible on PDF page 26 lists service enumeration, vulnerability assessment and a Nessus lab. Use Document Library searches to locate the actual sections; printed page references are not PDF page numbers.
- [[book-05]] — Cyber Operations: platform construction, defense and assessment. PDF page 39 illustrates distribution-specific networking; commands and supported platform versions must be rechecked before reuse.
- [[book-06]] — Dark Web: research/data mining and terrorism informatics. PDF page 58 concerns information fusion and terrorism research, not CVE detection. Keep it as contextual research, not a vulnerability playbook.
- [[book-07]] — EC-Council courseware: PDF page 47 lays out preparation, conduct and conclusion, and separates entry-point enumeration from vulnerability and penetration testing.
- [[book-08]] — Hack Instagram Methodes: a 20-page account-oriented document, not a general CVE catalog. Included in the source index; not treated as a validated testing authority.
- [[book-09]] — Hacking For Dummies, 3rd Edition: PDF page 26 describes a reference spanning planning, testing, fixing and an ongoing assessment program.
- [[book-10]] — Hacking VoIP: PDF page 41 distinguishes SIP signaling on port 5060 from media ports; see [[Attacker Vantage and Discovery]].
- [[book-11]] — Hacking with Python: programming/networking/web topics. PDF page 45 mentions python-nmap and BackTrack; old tool/platform recommendations need updating rather than verbatim reuse.

## Limits
Text extraction processed all 5,391 pages; it does not validate each assertion or preserve every table, diagram and screenshot. 92 pages have fewer than 40 extractable characters. No OCR was performed. Search result snippets are retrieval aids, not curated conclusions. Vendor advisories linked by each CVE remain the authority for applicability and fixes.
